# Exercícios do Bootcamp: Módulo de Banco de Dados (SQL & NoSQL)

Este repositório contém a resolução de todos os exercícios do módulo de **Banco de Dados**, cobrindo os fundamentos de bancos **Relacionais (PostgreSQL)** e **Não-Relacionais (MongoDB)**.

O ambiente de desenvolvimento é **100% containerizado** usando **Docker Compose**, permitindo que ambos os bancos de dados (Postgres e Mongo) rodem localmente com um único comando.

---

## Tecnologias Utilizadas

- **Docker & Docker Compose** — Para criar e orquestrar os contêineres dos bancos de dados  
- **PostgreSQL (`postgres:16-alpine`)** — Banco de dados relacional usado nos Exercícios 1 e 2  
- **MongoDB (`mongo:latest`)** — Banco de dados não-relacional usado nos Exercícios 3 e 4  
- **SQL (DDL/DML)** — CREATE TABLE, FOREIGN KEY, INSERT, SELECT, INNER JOIN, LEFT JOIN, WHERE, UPDATE  
- **NoSQL (BSON / Queries)** — `insertOne`, `find`, `updateOne`, `$set`, Schema Flexível  
- **Ferramentas Cliente**:  
  - Beekeeper Studio (SQL)  
  - MongoDB Compass (NoSQL)
